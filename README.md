# tvenoveja.cz

Static website with local Tailwind CSS build.

## Project structure

- `public/` - HTML and static assets
- `src/css/` - Tailwind source styles
- `src/js/` - source JavaScript
- `dist/` - build outputs consumed by HTML

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

The page entrypoint is `public/index.html`.
